# Asset Management System v2 Demo

สร้างใหม่ทั้งหมด แยกจาก Stock System เดิม 100%

รวมฟังก์ชันต้นแบบ:
- Individual Asset / Countable Equipment
- Custom Fields รายรายการ
- ตรวจนับย้อนหลังและส่วนต่าง
- Spoil / ชำรุด / Repair / PM พร้อมรูป
- Write-off พร้อมรายงานสะสม
- Custom Reminder
- Roles: Admin, Manager, Captain, Staff
- Assignment รายชิ้น/หมวด/พื้นที่/ทั้งระดับ/ทั้งขอบเขต
- My Tasks

หมายเหตุ: Demo ใช้ localStorage ยังไม่เชื่อม Firebase จริง และไม่ควรใช้ production ก่อนตั้ง Authentication, Security Rules, Storage และ Audit Log
