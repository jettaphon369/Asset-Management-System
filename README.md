# Asset Management System v2.1 Demo

อัปเดตจากภาพทดสอบบน iPhone:
- เมนูมือถือมี Overlay มืด
- แตะด้านนอกเมนูเพื่อปิด
- Sidebar เลื่อนได้เอง
- ปรับชื่อเมนูเป็นภาษาไทยมากขึ้น
- Dashboard เพิ่มการ์ด: ชำรุด/Spoil, กำลังซ่อม, ยังไม่เคยตรวจนับ, พบส่วนต่าง
- การ์ด Dashboard กดเข้าเมนูต้นทางได้
- ยังมี Individual Asset / Countable Equipment / Custom Fields / Count / Spoil / Repair / PM / Write-off / Reminder / Assignment

ยังเป็น Demo:
- ใช้ localStorage
- ยังไม่เชื่อม Firebase, Authentication, Storage, Audit Log
- ไม่ได้แตะเว็บ Stock เดิม
