# Asset Management System v1.0 (Phase 1 Demo)

โปรเจกต์นี้เป็นเว็บใหม่ทั้งหมด แยกจาก Stock System เดิมโดยสมบูรณ์

ฟีเจอร์ใน Phase 1:
- Dashboard สรุปจำนวนทรัพย์สิน มูลค่ารวม และสถานะประกัน
- เพิ่ม / แก้ไข / ลบ / ดูรายละเอียดทรัพย์สิน
- รูปภาพทรัพย์สิน พร้อมบีบอัดก่อนเก็บใน Demo
- วันที่รับเข้า ราคา หมวดหมู่ Serial ยี่ห้อ/รุ่น สถานที่ ผู้รับผิดชอบ
- ประกัน วันเริ่ม และวันหมด
- ค้นหาและกรองตามหมวดหมู่/สถานะ
- Responsive รองรับมือถือและ PC
- Export JSON สำรองข้อมูล Demo

สำคัญ:
- เวอร์ชันนี้ยังไม่เชื่อม Firebase
- ข้อมูลเก็บด้วย localStorage ในเบราว์เซอร์เครื่องที่เปิด
- ห้ามใช้เป็นระบบจริงก่อนเชื่อม Firebase และตั้ง Security Rules
- Stock เดิมไม่ได้ถูกแก้ไขหรือเชื่อมข้อมูลใด ๆ

เปิดใช้งาน:
เปิดไฟล์ index.html ผ่านเบราว์เซอร์ หรืออัปขึ้น GitHub Pages / Netlify เพื่อทดสอบหน้าตา
